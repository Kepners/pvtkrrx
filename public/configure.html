Where You Actually Configure
Two Real Setup Surfaces

If you privately host everything, configure on the machine that owns the route. Keep this shared page as the visual guide and fallback tool, not the default place you paste private localhost details.

Option 1

Windows Host

Use this when the Windows machine is the playback bridge. This is where PC Local and LAN Bridge are configured.

http://127.0.0.1:7000/configure
PC Local + LAN Bridge
Local runtime. Private services. Same-host control plane. Configure the Windows box first, then install the right route in Stremio.
PC Local LAN Bridge
  1. Open http://127.0.0.1:7000/configure on the Windows PC that runs PVTKRRX.
  2. Save your Prowlarr and qBittorrent details there, then run Auto Setup on that host.
  3. Install PC Local on that PC. Use LAN Bridge for the other home devices on the same Stremio account.
Option 2

Private Server

Use this when your own seedbox or VPS is the playback bridge. This is where Remote Seedbox is configured on your own HTTPS origin.

https://your-domain/configure
Remote Seedbox
Server runtime. Disk-backed config. Your own public HTTPS origin. Keep the browser-facing install URL on your domain, not on the public relay.
Remote Seedbox
  1. Open https://your-domain/configure on your own seedbox or VPS after the server installer is live.
  2. Save the server-side Prowlarr, qBittorrent, file serving, and path settings on that private server.
  3. Install Remote Seedbox from your own server origin. Keep pvtkrrx.cc out of the private control plane unless you intentionally want the official relay.
