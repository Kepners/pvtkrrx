What It Is — And What It Isn't

PVTKRRX is a private tracker bridge. It connects your Prowlarr and qBittorrent stack to Stremio. It is not a debrid service, not a media host, and not one universal install. Each route works differently because each setup is different. Built for operators who already run their own stack.

Frequently Asked Questions

What do I need to run PVTKRRX?
Prowlarr, qBittorrent, and Stremio are the baseline. Then choose the route that matches your setup: a Windows host for PC Local or LAN Bridge, or public HTTPS playback endpoints for Remote Seedbox.
Which route should I use first?
Start with PC Local if you are using the Windows PC that runs PVTKRRX. Use LAN Bridge for your TV, phone, and other home devices on the same account. Use Remote Seedbox only when playback needs public endpoints away from home.
Does PVTKRRX host media or work like debrid?
No. PVTKRRX is not a debrid service and not a third-party media host. It does not replace your own infrastructure. The playback path still comes from your own host machine, seedbox, or public file server endpoints.
Does PVTKRRX support sports in Stremio?
Yes. Sports is a first-class catalog alongside movies, TV, and your library. If your private trackers carry sports releases, PVTKRRX surfaces them in Stremio with artwork and genre filtering. It is not a separate live sports service — the content comes from the tracker side you already control.
