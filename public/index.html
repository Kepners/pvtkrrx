How It Works

> STEP 1: Configure

Run Auto Setup in Configure and save your local profile from the Windows host.

> STEP 2: Install

Install PC Local on the host machine. Install LAN Bridge on phone or Android TV.

> STEP 3: Stream

Stremio resolves stream metadata through hosted relay and plays over your LAN route.
