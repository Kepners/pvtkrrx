# PVTKRRX Route Framework

Updated: 2026-03-15

## Purpose

This file is the canonical definition of the current PVTKRRX setup model.
One runtime. Three install routes. Use the route that matches where playback happens.

For the broader runtime and storage model, see `docs/CURRENT_DESIGN.md`.

## Route Summary

| Route | Use it for | Install path | Playback path | Key constraint |
|---|---|---|---|---|
| `PC Local` | Same Windows machine that runs PVTKRRX | `http://127.0.0.1:7000/local/manifest.json?mode=local` | Built-in `/file` and `/playback` routes on the local server | Same-PC only |
| `LAN Bridge` | Home devices on the same LAN and Stremio account | Hosted manifest URL generated by configure with `lanPair*` fields | Hosted request redirects to active local host when heartbeat is online | Desktop app must stay running |
| `Remote Seedbox` | Away-from-home or direct public seedbox playback | Hosted HTTPS manifest URL | Public HTTPS ready-file qBit/Prowlarr/file server flow | Hosted Vercel does not serve `/playback` |

## Current Rules

1. `PC Local` is now a real addon, not a helper-only route.
2. `LAN Bridge` is the synced home-device addon.
3. `Remote Seedbox` is separate from LAN pairing and expects public HTTPS playback infrastructure.
4. Raw `192.168.x.x:7000` addon installs are still not a stable Stremio path.
5. `http://127.0.0.1:7000/...` remains the reliable manual install path for same-PC local use.

## What Each Route Exposes

### PC Local

- Movies
- TV
- Sports
- Library
- Direct same-PC playback from the local runtime

### LAN Bridge

- Same content catalogs as the configured host
- Hosted account-sync install path
- Hosted-to-local redirect when the pair heartbeat is online

### Remote Seedbox

- Same content model
- Intended for public HTTPS ready-file playback paths
- Ready-file-first on the hosted relay unless PVTKRRX is self-hosted on a playback-capable runtime
- Does not depend on LAN heartbeat/redirect behavior
- Hosted Vercel responses must not promise tracker `/playback` when the runtime cannot serve it

## Install Guidance

- Use `PC Local` only on the Windows host that runs PVTKRRX.
- Use `LAN Bridge` for phone, TV, web, and Apple TV on the same Stremio account as the host.
- Use `Remote Seedbox` when playback endpoints are already public and reachable over HTTPS.

## What `.pvtk` Is Not

There is no standalone `.pvtk` file format implemented in this repository.
What exists in the code today is the internal `pvtkrrx:` custom ID scheme used for sports and library items inside Stremio responses.
